# 帳本離線引擎（給朋友用的版本）

這裡只放記帳 App 的「手機離線引擎」——純前端檔案（HTML/JS/WASM），完全不含任何真正的帳務資料，也不含伺服器程式碼。

開啟方式：造訪 `https://kkljman-lab.github.io/?offline=1`（第一次要用這個網址，之後瀏覽器會記住）。

- 資料實際存在使用者自己手機的瀏覽器裡（不會經過這個網站、也不會經過原作者的電腦）。
- 目前「連結 Google 帳號」同步功能尚未支援這個網址（技術限制：Google 登入的安全機制只允許本機網址完成，公開網址需要額外的雲端小程式協助換證，尚未建置）。其餘記帳、分類、報表功能都可以正常使用。
